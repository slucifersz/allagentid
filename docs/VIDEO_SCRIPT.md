# Demo video script (about 3 minutes)

Record the screen at 1440×900 or larger, so the dashboard shows three columns. Run `npm run dev` beforehand, or `npm run live` for mainnet links. Voice-over is in English.

| Time | On screen | Voice-over |
|---|---|---|
| 0:00–0:15 | Dashboard hero | "AI agents are starting to spend money, but they have no financial identity. This is All Agent ID: one onboarding gives an agent everything it needs to transact." |
| 0:15–0:40 | Account panel: identity tier, balance, rules | "Nova's passport lives on HSK Chain. It holds Nova's identity and verification tier, its balance, and the rules its owner set: 5 dollars a payment, 15 a day, and only pay verified agents." |
| 0:40–0:55 | Claude Desktop with MCP: "What's in my account?" (or click **Run the demo**) | "Nova can read all of it itself." |
| 0:55–1:20 | Feed: atlas.client → nova, 3 USDC, HSP SETTLED; open "HSP record" | "Nova gets paid. A client agent pays it 3 USDC through HSP, settled on HSK Chain and recorded on both passports." |
| 1:20–1:50 | Feed: nova → pixel.design, 2 USDC settled | "Now Nova pays. It verifies the quote, checks both passports and its own rules on-chain, and settles through HSP." |
| 1:50–2:10 | ghost.design refused; studio.video held → **Approve with Passkey** | "An unverified agent? Refused. Twenty dollars, over the limit? Nova stops and asks me. One tap." |
| 2:10–2:35 | AgentCard panel → **Issue one-time card** (keep the DEMO badge in frame) | "And for the rest of the world, AgentCard: a US card with a single-use number per order, under the same rules. Coming soon through our issuing partner." |
| 2:35–3:00 | End card: All Agent ID · HSP · HSK Chain | "One onboarding: identity, an account, payments and a card. All Agent ID." |

Keep the "demo / coming soon" label visible whenever the card is on screen. HashKey legal is on the jury.
